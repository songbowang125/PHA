## Principal HOR Analysis (PHA) for Human Centromeres 
The analysis and reproduce scripts in PHA-Centromere paper, including 
* Centromere annotation (folder src/run_annot)
* Satellite-level analysis (folder src/analyze_sat)
* HOR-level analysis (folder src/analyze_hor)
* Epigenetic-level analysis (folder src/analyze_epigenetic)
